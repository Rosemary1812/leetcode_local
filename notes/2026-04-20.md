## 1. 215. 数组中的第K个最大元素

**思路**: 快速选择算法 (Quick Select) + Random Pivot

```python
from random import randint

def partition(nums, left, right):
    i = randint(left, right)
    pivot = nums[i]
    nums[i], nums[left] = nums[left], nums[i]
    i, j = left + 1, right
    while True:
        while i <= j and nums[i] < pivot: i += 1
        while i <= j and nums[j] > pivot: j -= 1
        if i >= j: break
        nums[i], nums[j] = nums[j], nums[i]
        i += 1; j -= 1
    nums[left], nums[j] = nums[j], nums[left]
    return j

def findKthLargest(nums, k):
    target = len(nums) - k  # 第k大 = 正序第n-k个
    left, right = 0, len(nums) - 1
    while True:
        i = partition(nums, left, right)
        if i == target: return nums[i]
        if i > target: right = i - 1
        else: left = i + 1
```

**核心**: 利用 partition 后 pivot 位置固定的特性，每次排除一半，平均 O(n)

## 2. 239. 滑动窗口最大值

**思路**: 单调递减队列 (Monotonic Queue)

```python
from collections import deque

def max_window(nums, k):
    ans = []
    q = deque()  # 存索引，保持递减
    for i, x in enumerate(nums):
        while q and nums[q[-1]] <= x:  # 维持单调递减
            q.pop()
        q.append(i)
        if q[0] <= i - k:  # 移出窗口外的
            q.popleft()
        if i >= k - 1:
            ans.append(nums[q[0]])
    return ans
```

**核心**: 队列头永远是当前窗口最大值的索引

## 3. 300. 最长上升子序列

**思路**: DP

```python
def lengthOfLIS(nums):
    f = [0] * len(nums)
    for i, x in enumerate(nums):
        for j in range(i):
            if x > nums[j]:
                f[i] = max(f[i], f[j])
        f[i] += 1
    return max(f)
```

**核心**: f[i] = 以 nums[i] 结尾的最长递增子序列长度

## 4. 309. 最佳买卖股票时机含冷冻期

**思路**: 记忆化 DFS (DP)

```python
from functools import cache
from math import inf

def maxProfit(prices):
    @cache
    def dfs(i, hold):
        if i < 0:
            return -inf if hold else 0
        if hold:
            return max(dfs(i - 1, False), dfs(i - 2, False) + prices[i])
        return max(dfs(i - 1, True), dfs(i - 1, False))
    return dfs(len(prices) - 1, False)
```

**核心**: hold 状态转移时冷冻期 i-2，返回时 -inf 表示无效状态

## 5. 322. 零钱兑换

**思路**: 背包 DP (完全背包)

```python
from math import inf

def coinChange(coins, amount):
    f = [0] + [inf] * amount
    for x in coins:
        for c in range(x, amount + 1):
            f[c] = min(f[c], f[c - x] + 1)
    return f[amount] if f[amount] != inf else -1
```

**核心**: f[c] = 凑成金额 c 所需最少硬币数
